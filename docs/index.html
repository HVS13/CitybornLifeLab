Install Cityborn Life Advisor

Source & full instructions · Open the game

Install

  1. Install Tampermonkey from its official browser-store links.
  2. Click the install button and confirm in the manager. If it opens as text, create a new userscript, paste the entire file, and save. If you installed the earlier local script, remove that copy first.
  3. Reload the game and look for Cityborn Life Lab 2.2.0. The manager keeps the original script name for updates.

Play toward your goals

  • Browse traits & achievements: see all 50 displayed traits and 169 achievements, filter by type, and read the game's achievement hints. Browsing remains available if the game updates or workers are blocked.
  • Find a life: choose minimum final Health, Sanity, Wealth, Network and Reputation. Require traits or achievements, avoid unwanted traits, and optionally set a minimum age or alive ending.
  • Search a specific seed or start with 1–3 random seeds. Compare completed endings. Every result lists its original targets; partial results list what failed.
  • Play this life: start a selected seed, resume saved progress, or plan the rest of your current life. Following checks each live state before choosing.
  • Saved lives: keep and compare routes, import/export them, and copy seeds. Existing v1/v2 exports remain supported.
  • Copy stats and traits directly from your current or ended life. New search targets do not erase the route you are already playing.
  • Following pauses for names and reflections. Submit your text in the game, then click Resume after typing. If needed, the remaining route is recalculated using its original goals.
  • Verified cosmetic entries retain the same remaining choices. Choose a goal-first comparison order: recommended survival/wellbeing, lifespan, a stat, achievement rarity, or native Fixer combat rating. These metrics are not a win probability.

Know the limits

The planner searches complete alternative routes within a fixed budget. It can miss possible routes, and some goals conflict. Predictions are not guaranteed optimal lives. The script sends no gameplay data to a server and does not fabricate achievements or load route snapshots into your game save. It supports the inspected game bundle and stops on a different version.
