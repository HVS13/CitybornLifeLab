Install Cityborn Life Advisor

Source & full instructions · Open the game

Install

  1. Install Tampermonkey from its official browser-store links.
  2. Click the install button and confirm in the manager. If it opens as text, create a new userscript, paste the entire file, and save. If you installed the earlier local script, remove that copy first.
  3. Reload the game and look for the Cityborn Life Advisor panel.

Play toward your goals

  • Evaluate choices ranks unlocked options using the game's inspected simulation.
  • Choose Balanced, Deep, or Life rollout evaluation. Apply a recommendation once or let Auto follow it.
  • Start Auto applies advice for this life. Stop, Escape, or manual game interaction returns control. Use the game's x32 speed for faster progress.
  • Select achievements or traits and search At birth for fast starting-condition matches, or At end of simulated life for full-life matches.
  • Start a found seed from the game's home screen, then enable Auto to follow its stored route. Full-life searching can take time; begin with 1–5 seeds.
  • Your goals and latest route survive reloads. Export/import routes, copy seeds, and inspect missing goals in explicitly labeled partial results. Imports are checked by replaying their actions in the native engine.

Know the limits

Advice uses bounded lookahead, not a proof of the best possible life. Some goals conflict or require later quest prerequisites the search may miss. The script sends no advisor data to a server and does not fabricate achievements. It supports the inspected game bundle and stops on a different version.
